Key Exam Insights (Ch 7)

• All Designs are Models; a model of the problem is an analysis model, of the solution is a design model.
• Encapsulation vs Abstraction: Encapsulation bundles data & functions into a unit with data hiding; Abstraction suppresses non-essential details.
• Operation vs Method: Operation is the specification/responsibility; Method is the implementation. Overloaded operations have multiple methods.
• Association vs Link: Association exists between classes (static); Links exist between object instances (dynamic).
• Aggregation vs Composition: Aggregation (hollow diamond) is part-whole with independent lifecycles; Composition (solid diamond) is existence-dependent.
• Interaction Diagrams: Sequence diagrams show chronological message sequence per use case; Collaboration shows object link structure.
• State Charts: Model state changes of a single object across multiple use cases (not multi-object collaboration).
