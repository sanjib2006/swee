Key Formulas & Rules

• COCOMO Precedence: Size → Effort → Duration → Cost.
• Putnam Compression: Effort scales as $(t_1 / t_2)^4$. Cutting time by 50% increases effort 16×.
• Boehm's Limit: Max schedule compression is ~25% of nominal time.
• CPM Critical Path: Longest path in time ($ST = LS - ES = 0$).
• Gantt vs PERT: Gantt = resource allocation; PERT = progress monitoring & control.
